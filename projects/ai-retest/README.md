# AI ReTest Agent | 모델 업데이트 전후 오류를 찾는 재검증 에이전트

“전체 정확도가 올랐는데, 어제까지 알아보던 전차를 오늘은 놓칠 수도 있을까?” 팀 **‘전선을 간다’**의 팀장으로 이 질문에서 출발해, 이전 버전이 맞히고 새 버전이 틀린 사례를 찾아주는 에이전트를 기획하고 제작했습니다. **방산 AI 아이디어 경진대회 최우수상**을 받았습니다.

- **비교 방법** — 동일한 시험 표본에 대한 두 모델의 예측을 맞춰 보고, 새로 틀린 사례를 장면 조건과 객체 종류별로 집계했습니다. 시험 담당자는 오류가 몰린 조건을 선택해 원본 사진과 두 버전의 예측을 함께 확인할 수 있습니다.
- **시연 결과** — CIFAR-100 공개 사진에 저조도·흐림·가림 등 7가지 장면 조건을 적용한 **3,514건**에서 전체 정확도는 **54.58%에서 58.31%**로 올랐습니다. 그런데 이전 버전이 맞힌 **157건**을 새 버전이 틀렸습니다. 특히 저조도 전차 정확도는 **58%에서 41%**로 떨어졌고, 이 조건에서 새로 틀린 **18건 모두** 전차를 배경으로 분류했습니다.
- **후속 시험** — 저조도 전차 사진의 밝기와 흐림 정도를 바꿔 두 버전에 다시 입력하는 시험안을 제시했습니다. 담당자가 판단 근거를 확인할 수 있도록 시험 문서에서 관련 문단과 쪽 번호를 찾아 PDF 검토 보고서로 내보내는 흐름을 구성했습니다.

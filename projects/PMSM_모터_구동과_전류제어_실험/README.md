# PMSM 전류제어 | 학부연구 · 대한전기학회 포스터 제출

영구자석 동기전동기(PMSM)에 전류를 지령해도 모터가 돌지 않는 문제를 조사했습니다. PLECS에서 만든 제어 모델, STM32의 PWM 출력, 인버터 게이트 신호를 차례로 대조했습니다. 오실로스코프로 파형을 측정한 결과 PWM 극성과 구동 보드의 게이트 논리가 맞지 않는 것을 확인했습니다. 생성된 C 코드의 PWM 설정을 수정한 뒤 실제 모터가 회전했습니다.

- **실험 구성** — STM32G431RB, X-NUCLEO-IHM08M1 인버터, Teknic M-2310P 모터, 3-shunt 전류 측정, ABZ 엔코더를 사용했습니다.
- **전류 추종** — ADC 오프셋을 보정하고 PLECS의 d축·q축 PI 제어기에서 지령과 측정값을 비교했습니다. d축 전류가 0.1 A 지령을 따라가는 것을 확인했습니다.
- **연구 발표** — 구동 실패 원인, 수정 전후 파형과 전류 추종 결과를 에너지신산업 학부연구 성과발표회 자료와 대한전기학회 포스터로 정리했습니다.

팀장으로 실험 결과를 정리하고 발표해 **2026 E-SynC! 학부생연구프로그램 성과발표회 최우수상**을 받았습니다.

## 제어기를 실물에서 검증한 방법

PLECS에서 d축과 q축 전류 제어기를 구성한 뒤 STM32G431RB에서 실행했습니다. 인버터에서 측정한 상전류와 엔코더의 회전자 위치를 이용해 d축·q축 전류를 구하고, 각 축의 지령과 측정값의 차이를 PI 제어기에 입력했습니다. 제어기가 계산한 전압 지령은 인버터의 PWM 듀티에 반영했습니다.

발표자료에 담은 실험에서는 회전자를 정렬한 뒤 d축에 0 A, q축에 약 1 A를 지령했습니다. 실제 회전 영상과 두 축의 전류 파형을 함께 확인했습니다. 후속 시험에서는 지령과 부하를 바꾸면서 정착시간과 전류 리플을 비교할 계획입니다.

# 에너지신산업 AI 영상 제작 경진대회

**타 대학 학생들과 에너지신산업 주제 영상 제작 · 우수상**

4박 5일간 타 대학 학생들과 에너지신산업을 주제로 영상 「DREAM TO ENERGY」를 제작했습니다. 시나리오를 장면 단위로 나누고 이미지와 영상이 이야기 흐름에 맞도록 생성 프롬프트를 수정했습니다. 이 작품으로 「AI 활용 영상 제작 전문 교육 및 경진대회」에서 팀 우수상을 받았습니다.

## 프로젝트 질문

AI가 다음 PI 게인 실험을 추천하면, 식각 장비 챔버의 압력 안정화 조건을 찾는 평가 횟수를 줄일 수 있을까?

이 자료는 물리식 기반 시뮬레이션으로 생성한 데이터다. 실제 장비에서 측정한 데이터는 확보하지 않았다. 논문에서 압력 모델의 구조를 참고하고 모든 수치 계수는 교육용으로 가정했다.

## 직무와 업무 상황

설비기술 엔지니어가 정해진 압력 지령을 빠르고 안정적으로 추종하도록 장비 제어 조건을 시험하는 상황을 설정했다. 삼성전자 DS 메모리사업부 설비기술 공식 소개에는 압력 등 HW 제어기술 개발, 신설비 최적화 조건 확보, 설비 센서와 데이터 활용 업무가 제시되어 있다.

## 모델과 초기 조건

압력 P는 mTorr, 밸브 개도 u는 0~1이다.

- 챔버 부피 V = 10 L
- 가스 유입 Q = 200 mTorr·L/s = 0.2 Torr·L/s
- 유효 배기속도 S(u) = 1 + 8u L/s
- 압력식 dP/dt = (Q − S(u)P)/V = 20 − (0.1 + 0.8u)P
- 밸브식 du/dt = (u_command − u)/0.5
- 초기 P = 40, u = 0.5, 적분상태 I = 0
- 초기 평형 검산 200 = (1 + 8×0.5) × 40
- t = 0에 목표 압력을 40에서 50 mTorr로 변경
- 온도와 유입 가스량은 일정하며, 센서 잡음·반응 부산물·플라즈마 변화·식각 깊이 및 형상은 모델에 포함하지 않음

제어식은 e = (50 − P)/10, u_command = clip(0.5 − Kp×e − I, 0, 1), dI/dt = Ki×e다. 제어기는 0.01초 간격으로 갱신한다. 밸브가 포화되어 있고 오차가 포화를 더 강하게 만드는 방향이면 해당 틱의 적분을 멈춘다. 물리 상태는 구간별 일정 명령으로 RK4 적분한다.

Kp는 무차원, Ki는 s⁻¹이며 정규화한 오차를 사용한다. 다른 장비나 오차 단위를 사용하는 제어기에 수치를 그대로 옮길 수 없다.

## 25개 후보와 판정

Kp, Ki 각각 [0.05, 0.10, 0.15, 0.20, 0.25]의 5단계다. Kp를 먼저 고정하고 Ki를 순서대로 바꾸어 E01~E25를 부여했다. 이 범위는 앞선 예비실험을 참고해 정했다.

- 초과율 = max(0, P_max − 50) / (50 − 40) × 100%. 목표값 대비 비율과 분모가 다르다.
- 압력 초과 허용 기준은 5%, 따라서 P_max ≤ 50.5 mTorr다.
- 안정화 시간은 49.8~50.2 mTorr에 진입하여 30초 관측 종료까지 유지한 최초 시점이다. 최소 2초의 잔여 관측시간을 요구한다.
- feasible은 초과 기준을 만족하고 안정화 시간이 확인된 경우다.
- qualified는 feasible이면서 안정화 ≤ 5초인 경우다.
- 5초와 5%, 허용대역, 30초 관측은 모두 과제용 가정이다.
- 밸브 이동량은 개도 변화 절댓값의 누적 합 × 100이다. 단위는 %p 누적이며 실제 마모량을 의미하지 않는다.

## 탐색 비교

초기 5개는 E01, E05, E13, E21, E25다. AI는 초기 5개를 포함한 10회 예산에서 작동한다. 추천 함수에 입력하는 관측값에는 이미 실행한 조건만 포함한다. 코드에서는 AI 순차 탐색을 먼저 실행하고 전수평가를 진행한다. 같은 초기 결과로 시작하는 무작위 탐색은 미실행 20개 중 서로 다른 5개를 고른다.

두 개의 GP가 초과율과 안정화 시간을 각각 추정한다. 좌표는 0~1로 정규화하며 RBF 길이척도 0.4와 대각 안정화항 10⁻⁶을 고정한다. 관측값은 각 시점의 평균과 표준편차로 정규화한다. 기대 개선량 × 초과 기준 만족 확률로 후보를 고른다. 합격 관측값이 없으면 제약 만족 확률로 탐색한다. 미안정화는 GP 학습에서 30.01초로 대체하는 단순 근사다.

10회 최종 결과는 가능한 추가 5조건 묶음 20C5 = 15,504개를 전부 평가했다. 중간 회차 그래프는 seed 42로 만든 1,000개 무작위 순서의 중앙값과 사분위 범위다. 무작위 순서의 평균 성능을 일반적인 엔지니어의 수동 튜닝 성능으로 해석할 수는 없다.

## 계산 결과

- 25개 중 feasible 조건은 5개이며, qualified 조건은 1개다.
- 최적 후보는 E22, Kp = 0.25, Ki = 0.10이다.
- 최대 압력 50.1514 mTorr, 초과율 1.5143%, 안정화 2.66초다.
- AI는 9회차에 E22를 선택했고, 10회 후 최선도 E22였다.
- 같은 10회 예산에서 무작위 탐색의 최선 안정화 시간 중앙값은 10.59초다.
- 무작위 10회 탐색에서 E22를 포함할 확률은 정확히 25%다.
- AI가 확보한 안정화 시간은 무작위 중앙값 대비 약 74.9% 짧다. 이는 확보한 제어 성능 비교다.
- 전수 25회와 비교하면 E22의 발견 시점 9회는 64% 적다. 전체 최적이라는 사실은 25개 전수 평가 후 알 수 있다. 따라서 최적성을 보증하는 실제 평가 비용을 64% 절감했다고 해석하지 않는다.

## 확인한 것과 남은 검증

- 25개 모두 RK4 적분 간격을 0.01초에서 0.005초로 줄여 비교했다. 제어주기는 동일하게 0.01초로 유지했다. 최대 압력 차이는 8.90×10⁻⁹ mTorr다.
- 밸브 개도 고정 45%에서 해석적 평형압력 43.47826 mTorr와 수치 계산이 일치했다.
- 브라우저 JavaScript와 Python의 25개 최대 압력·안정화 시간·합격 판정이 일치했고, AI의 10회 선택 순서도 일치했다.
- 이러한 확인은 코드와 수치 계산의 일관성을 검증한다. 실제 설비 파형에 맞춘 파라미터 식별, 센서 잡음과 환경 변화 검증, 실제 식각 품질 검증은 후속 단계다.
- 예비실험을 참고한 범위에서 실행한 단일 사례이므로 AI가 모든 환경에서 항상 우수하다는 결론은 내릴 수 없다.
- 이전 예비 코드의 전진 오일러 계산을 RK4로 바꾸고 안정화 후 최소 2초 관측 기준을 추가했다. 따라서 이전 2.69초 대신 이번 버전에서는 2.66초다. 발표에는 이번 v2 자료를 일관되게 사용한다.

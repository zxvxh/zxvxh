# 식각 챔버 압력 제어 실험실

김지호 · 전북대학교 전기공학과 · 반도체 공정설비 부트캠프

**[웹 실험실 바로 실행하기](https://jiho-etch-pressure-lab.kjiho1023.chatgpt.site/)**

모터 전류 PI 제어 경험을 챔버 압력 제어에 적용한 가상 실험 프로젝트입니다. PI 제어기가 배기 밸브를 조절하고, AI는 다음에 시험할 Kp·Ki 조합을 추천합니다. 구현과 문서화에 AI 도구를 활용했습니다.

## 주요 기능

- Kp·Ki 입력 및 30초 압력 파형 확인
- 25·100·400조합 비교와 AI 다음 실험 추천
- CSV·JSON 업로드 분석 및 결과 다운로드

## 실험 결과

기준 25조합에서 같은 초기 5조건과 총 10회 예산으로 비교했습니다.

- AI는 **9회차에 E22** 발견: 안정화 **2.66초**, 초과율 **1.51%**
- 무작위 탐색이 찾은 최선 조건의 안정화 시간 중앙값: **10.59초**

위 수치는 실제 장비 측정이 아닌 고정 모델의 계산 결과입니다. 안정화 시간 비교이며, 실제 개발기간·비용 절감을 검증한 것은 아닙니다.


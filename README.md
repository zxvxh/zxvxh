# 김지호 · zxvxh

전북대학교에서 전기공학과 방위산업 융합전공을 공부하는 김지호입니다. 학부연구에서는 모터의 전류를 제어하는 코드를 보드에 올리고, 오실로스코프로 신호를 측정해 모터가 회전하지 않던 원인을 찾았습니다. 창업 프로젝트 SeatFlow에서는 학생과 관리자가 빈 좌석을 확인할 수 있는 웹을 만들었습니다. 앞으로는 로봇과 전기제품의 구동부를 설계하고, 직접 시험해 성능을 확인하는 엔지니어로 성장하고 싶습니다.
